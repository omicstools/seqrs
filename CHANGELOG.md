## [1.0.0] - 2026-06-09

### Added
- Initial release of seqrs
- Fast FASTQ/FASTA statistics and filtering
- Support for multiple sampling methods (by number and proportion)
- Rust 1.96.0 compatibility
- Linux amd64 binary distribution

### Changed
- Updated to Rust 2024 edition
- Updated all dependencies to latest versions

### Fixed
- Compatibility with rand 0.9 API changes
